### See what your dApp reveals.

Nodal is building privacy visibility for Web3, starting at the request layer: every wallet value an app sends, who receives it, and in which field. Network privacy protects the route. Nodal shows what travels on it.

**Website:** [nodaltrace.si](https://nodaltrace.si)<br>
**Docs:** [nodaltrace.si/docs](https://nodaltrace.si/docs/)<br>
**Roadmap:** [nodaltrace.si/#roadmap](https://nodaltrace.si/#roadmap)<br>

### What Nodal is building

```
   NETWORK LAYER                 REQUEST LAYER                     ON-CHAIN
   who · when · from where       what the dApp sends               public ledger

  ┌───────────────────────┐    ┌────────────────────────────┐    ┌─────────────────┐
  │  mixnets · VPNs · Tor │──► │  wallet  ·  host  ·  field │──► │  explorers      │
  │  e.g. the Nym mixnet  │    │  ███  NODAL TRACE LAB  ███ │    │  indexers       │
  └───────────────────────┘    └────────────────────────────┘    └─────────────────┘
                                 Nodal's scope · in development
```

**The next layer.** A request can cross a mixnet untouched and still carry its user's wallet address. Nodal is exploring how apps that route through the Nym mixnet, via [anon-rpc](https://github.com/nymtech/anon-rpc-worker), can be tested for requests that leave the private route.
